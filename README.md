 # Decorators-and-Generators-Using-Python
Decorators: A decorator is like a function that modifies or extends the behavior of another function
@wakeup_remainder: Alerts you to wake up
@water_remainder: Encourages hydration
@workout_remainder: Tracks workout duration
@cooking_timer: Measures cooking time
@groceries_remainder: Prevents forgetting items
@sleep_tracker: Tracks sleep duration
Generators: A generate is a special type of function that can be used to generate a sequence of values instead of computing them all at once.
Generating Fibonacci Series
Movie Ticket Booking
Traffic Light System
ATM Cash Dispenses
